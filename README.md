# Lemurian Reimagined

**Seven Zones of a Living Civilization**

An offline-capable responsive interactive prototype of a seven-zone Lemurian-inspired civilization. Open `index.html` in a browser; no dependencies or API keys.

## Features
- Clickable circular map with seven zones and a central sanctuary
- Explore, Build, Sources, and Journal tabs for every zone
- Personal notes saved locally in browser storage
- Responsive interface and keyboard-accessible buttons
- Research distinctions between esoteric narratives and evidence-based proposals

## GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)**, and **Save**. Once published, the expected site address is https://tonyparker1964.github.io/Lemurian-Reimagined/ .
